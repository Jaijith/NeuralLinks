<product_requirements>
The application aims to be an AI-powered dating app with a dual-world system. Users have Real and Avatar personas, with AI LLM agents facilitating interactions via Graph RAG. Key features include Google OAuth, AI-driven matchmaking, and a social media-style interface with profiles, feeds, search, and friends. The Real World should display realistic profiles, while the Avatar World (now Maya) needs a distinct, stylized, cartoonish (originally cyberpunk/bioluminescent, then Avatar-movie style) aesthetic with an anime image and a nickname for the avatar. Each user must have automatically generated, distinct Real and Avatar profiles with separate editable data (bio, interests) and independent posts, all tied to the same user account. The UI must ensure excellent readability across all world modes, correct display of world-specific content (profiles, friends, posts), functional buttons, and consistent global navigation. The Real World and Avatar World have been renamed to Sense and Maya respectively.
</product_requirements>
