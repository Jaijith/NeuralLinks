<product_requirements>
The goal is to build an innovative AI-powered dating app, similar to Tinder, but featuring AI LLM-based agents as avatars of real people. These avatars should accurately reflect real individuals by analyzing social media and e-commerce data, supplemented by manual profile creation via avatar conversations. The application requires Google-based authentication.

Key features include:
1.  **AI Agents & Graph RAG**: LLM agents for conversations, leveraging Graph RAG to accumulate and expand user information for personalized interactions. Azure OpenAI is the chosen LLM integration.
2.  **Matching & Scoring**: AI agents conduct initial conversations, and humans receive top-pick matching profiles with validation scores. Matchmaking should evolve through progressive conversations between avatars, leading to levels of engagement.
3.  **Social Media Interface**: The app should resemble a social media site (Facebook-style) with user profiles, activity feeds, posts, photos, search functionality, and a friend system.
4.  **Dual World System**: A global toggle to switch between a Real World (displaying real profiles with realistic images/names) and an Avatar World (featuring stylized, e.g., anime-style, avatar profiles with specific activities, posts, and a Neural Links matchmaking tool). The Avatar World should have a distinct, radical visual style (e.g., cyberpunk, bioluminescent).
5.  **User Profile & Editing**: Users need their own Facebook-style profile page, distinct from the dashboard, with edit options for posts and avatar/self customization, including a personal Real/Avatar toggle.
6.  **Bot Profiles**: Populate the platform with 50 diverse bot profiles (real and avatar) including anime images, detailed activities, and pre-friended relationships.
</product_requirements>
